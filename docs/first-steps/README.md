One file per person. Read yours top to bottom, do the steps in order.

- `ARINZE.md` — the minigame system (build + wire)
- `BENJAMIN.md` — Chapter 12 endgame
- `LUCA.md` — interface & polish

Everything here assumes you've skimmed `docs/WORK_DIVISION.md` (the whole board) and, if you're writing code, `docs/MINIGAME_CONTRACT.md`.

**One team-wide dependency before anything else:** Arinze commits the working tree. Nobody branches off an uncommitted base. It takes ten minutes and it's step 1 of `ARINZE.md`.

**Second team-wide item:** Ben can't run the repo, so somebody has to put a playable build somewhere he can reach it. That's step 3 of `LUCA.md`, and until it's done Ben can't review anything against the real thing.
