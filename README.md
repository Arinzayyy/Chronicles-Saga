Halima Investigation – README
Game Description
Halima Investigation is a narrative-driven interactive mystery game set in modern-day Nigeria with supernatural undertones. You play as the Viewer, an ally whom the missing bounty hunter Halima trusted with her life. When she vanishes under mysterious circumstances, you must help her friends uncover the truth through a series of high-stakes decisions.

Unravel clues, navigate dangerous alliances, and follow the trail into the shadows. Every choice you make shapes the outcome of the story, leading to multiple possible endings—some triumphant, others tragic.
Features
Halima Investigation features a branching narrative with intense mystery and supernatural elements. Multiple endings are determined by your choices as you interact with a cast of complex characters. The story is character-driven, and your ability to build trust or suspicion with the crew—Murna, Marie, Kelvin, Ayo, and Pitch—will influence how the investigation unfolds.

The game runs through a simple yet clean GUI built with Python and Tkinter.
How to Play
Step 1: Install Python
Ensure you have Python 3.8 or later installed on your system.
You can download it from: https://www.python.org/downloads/
Step 2: Download Project Files
Download all project files into a single folder:
- gui.py (game launcher)
- story_engine.py (story system)
- masquerade_story.json (story content)
Step 3: Run the Game
Open a terminal or command prompt and navigate to the folder where the files are saved. Then run:

python gui.py

The game will launch in a graphical interface.
Step 4: Play
Read the scenes carefully.
Choose from the available options to progress through the investigation.
Your choices will determine who survives and whether the group discovers the truth about Halima's disappearance.
Level 1: Halima’s Investigation
In this first level, you guide Murna, Marie, Kelvin, Ayo, and Pitch as they try to uncover what happened to Halima. Follow leads, question allies, and analyze clues to reveal where she has been taken.

Objective: Discover where Halima is being held.
Failure: Alienate allies, miss crucial evidence, or fall into a dead-end path.
